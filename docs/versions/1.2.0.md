# v1.2.0

## 更新内容

数据全面落库（待办、随手记、音乐从 localStorage/IndexedDB 迁移至数据库，旧数据首次加载自动迁移），新增任务管理板块：支持任务名、目的、关联文件与知识、完成状态，重要性分三档，父子任务多级拆分，列表与时间线两种视图。

## 主要新增文件

- `src/actions/widgets.ts`、`src/actions/music.ts`、`src/actions/tasks.ts` — 待办/随手记/音乐/任务服务端操作
- `src/components/tasks/task-modal.tsx`、`src/components/tasks/task-card.tsx` — 任务编辑弹窗与任务卡片
- `src/app/dashboard/tasks/page.tsx` — 任务管理页面（列表/时间线视图）

## 主要修改

- `prisma/schema.prisma` — 新增 Todo、Note、MusicTrack、Task、TaskLink 数据模型与 TaskPriority 枚举
- `src/store/widgets.ts` — 重写为后端数据源，内置本地旧数据自动迁移
- `src/components/layout/dashboard-layout.tsx` — 工作区第一栏新增"任务管理"入口
- `src/components/layout/sidebar-todo.tsx`、`sidebar-notes.tsx`、`notes-modal.tsx`、`sidebar-music.tsx` — 接入后端数据源
- `src/types/index.ts`、`src/lib/validations.ts` — 新增对应类型与校验规则
- `package.json` — 版本号提升至 1.2.0

## 其他

- 数据库结构已通过 `npx prisma db push` 同步；任务可通过"添加子任务"拆分多层，点击任务展开即可查看关联的文件与知识
