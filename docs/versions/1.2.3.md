# v1.2.3

## 更新内容

音乐盒操作台重做为千禧风 Y2K 复古播放器（黑白灰单色版）：Winamp 风格银色金属机身 + 灰白 LCD 频谱屏、可拖拽进度与音量滑块、随机 / 单曲循环、旋转 CD 唱片与磁带装饰，右侧为 Winamp 风格播放列表编辑器，支持播放进度跳转与自动切歌；整体为黑白灰单色，去除彩色圆点与绿色荧光，契合全站蓝图单色风格。

## 主要新增文件

- `src/components/music/y2k-player.tsx` — Y2K 播放器机身（标题栏 / LCD 频谱 / CD 唱片 / 控制键 / 音量 / 磁带装饰）
- `src/components/music/y2k-playlist.tsx` — Winamp 风格播放列表编辑器

## 主要修改

- `src/app/dashboard/music/page.tsx` — 音乐盒操作台页面重写，集成 Y2K 播放器与播放列表，新增进度跳转、音量控制、随机 / 单曲循环、自动切歌
- `src/app/globals.css` — 新增 Y2K 播放器样式（金属质感 / 灰白 LCD / 拟物按钮 / 跑马灯 / 频谱动画）
- `package.json` — 版本号提升至 1.2.3
- `README.md` — 同步更新至 v1.2.3（功能说明 / 目录树）

## 其他

- 视觉语言参考小红书"沐果素材"Y2K 音乐播放器素材包，仅借鉴风格，全部为纯 CSS 实现，未引入任何版权素材
- 配色为黑白灰单色，无彩色元素
