# v1.2.1

## 更新内容

随时记写入口页面化：点击侧边栏"随时记写"跳转到独立工作台页面，全文在中间操作台呈现，长文本自动换行不再影响观览；每日待办功能合并入任务管理，构成长期工作流，每日任务完成后由空圆圈变为实心圆圈；移除工作区左上角的随时记写入口。

## 主要新增文件

- `src/app/dashboard/notes/page.tsx` — 随时记写工作台页面（全文呈现 + 长文本换行）
- `docs/开发日志[2026.8.15].md` — 本版本开发日志

## 主要修改

- `src/components/layout/sidebar-notes.tsx` — 标题改为"随时记写"页面入口（跳转工作台），快速记录区可折叠
- `src/components/layout/sidebar-todo.tsx` — 改为"今日任务"（调用任务管理 API），完成项显示实心圆圈
- `src/components/tasks/task-card.tsx`、`src/app/dashboard/tasks/page.tsx` — 完成状态图标由对勾改为实心圆圈
- `src/components/layout/dashboard-layout.tsx` — 移除左上角随时记写按钮，删除 notes-modal 引用
- `src/actions/widgets.ts`、`src/store/widgets.ts`、`src/lib/validations.ts`、`src/types/index.ts` — 移除每日待办相关代码
- `prisma/schema.prisma` — 移除 Todo 模型（每日待办已合并入任务管理）
- `package.json` — 版本号提升至 1.2.1

## 其他

- 数据库结构已通过 `npx prisma db push` 同步（删除 Todo 表，原表无数据无影响）
- 任务完成后圆圈图标由空心变为实心，与每日完成任务的"实心圆圈"状态一致
