# v1.1.2

## 更新内容

后台管理系统"自定义背景壁纸"上传优化：上传前使用 canvas 智能重绘，解决低分辨率图片 cover 放大后模糊的问题，同时压缩超大图片体积避免 localStorage 存储超限。

## 主要新增文件

- `src/lib/wallpaper.ts` — 壁纸图片处理工具（EXIF 方向修正、智能缩放重绘、体积兜底降采样）

## 主要修改

- `src/components/layout/dashboard-layout.tsx` — 上传逻辑改为异步智能优化：
  - 低分图（最长边低于屏幕尺寸或 1600px）等比放大到屏幕级尺寸，高质量重采样插值，cover 铺满后清晰
  - 超大图（最长边超 2560px）等比压缩，控制 data URL 体积，避免 localStorage 配额溢出
  - 自动应用 EXIF 旋转方向（手机竖拍照片不再横置）
  - 透明图保留 PNG 格式，体积过大时回退 JPEG（白底）
  - 上传处理中显示"正在优化图片…"状态，禁用按钮防止重复操作
  - 优化失败自动回退原始图片，保证功能可用
- `package.json` — 版本号提升至 1.1.2

## 其他

- 壁纸存储仍为 data URL（localStorage），内部存储键不变，不影响既有壁纸数据
