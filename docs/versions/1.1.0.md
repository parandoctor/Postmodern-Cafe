# v1.1.0

## 更新内容

后台系统 UI 全面重做：取消七种彩色分类，统一为黑白灰阶 + Notion 风格侧边栏与立体感卡片；左侧新增每日待办、随手记与音乐盒（支持本地上传音乐播放），右侧新增日历与计时器；移除左下角悬浮小球（光标拖尾）；壁纸下架预设，仅保留默认浅色与自定义壁纸。所有分类仅更换颜色，功能不受影响。
