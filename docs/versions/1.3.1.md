# v1.3.1

## 更新内容

后台从文件管理为中心的三栏工作台，重构为只保留「笔记管理 / 美学空间 / 实用工具」三个模块。登录后直接进入笔记管理，旧文件、分类、收藏、最近、回收站、任务、今日任务和音乐盒地址全部兼容跳转。全站视觉改为纯白背景、黑色文字、细线分隔与宋体标题，移除 Y2K、终端、ASCII、扫描线、蓝图、壁纸、明暗切换和全站自动播放 BGM。

笔记管理新增 Markdown 编辑/预览、800ms 自动保存、Ctrl/⌘+S、笔记标题自动提取，以及图片、视频、音频、文档和压缩包文件抽屉。美学空间新增单实例音乐播放器与 Fabric.js 图片编辑器；音乐在收起侧栏、切换后台模块时持续播放，不再出现多实例叠音。实用工具新增跨页面持续倒计时与月历。
