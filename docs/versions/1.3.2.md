# v1.3.2

## 更新内容

三节点空间图进一步收紧：画布约 780×520，三根竖线移动到 30% / 50% / 70%，节点保持错位并缩短引线与左右箭头。中央半调阴影改为主动效层，以约 6 秒周期持续漂移、呼吸，并跟随鼠标位置偏移；悬停模块、节点或线条时，对应区域点阵变深、整组元素上浮、节点外圈放大、细线方括号出现，同时线段内增加沿线路移动的高光。

首页与后台主要按钮统一为新的 MotionButton：主按钮持续轻微浮动，所有按钮悬停上浮并扫光，Secondary 悬停黑白反转，Icon 按钮悬停浮动与旋转，点击回弹。首页新增逐行滚动揭示：Hero 在首屏按行出现，功能区与 About 在进入视口时逐行上浮淡入。
