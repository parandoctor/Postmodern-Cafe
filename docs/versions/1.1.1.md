## 更新内容

项目由"收纳盒"更名为"后现代咖啡馆"，定位升级为一站式综合服务平台（生活记录、资料归档、事务处理）。首页宣传标题与 UI 同步更新，全站字体切换为思源黑体（Noto Sans SC）；README 重写新手向使用步骤，补充 Node.js 环境安装与运行说明。后台管理系统品牌字样跟随更新（侧边栏 Logo、顶栏、环境变量 NEXT_PUBLIC_APP_NAME）。

## 主要新增文件

- `docs/开发日志[2026.8.3].md` — 版本开发记录（含前后端分离技术栈调研）
- `.env.example` — 环境变量模板文件

## 主要修改

- `src/app/layout.tsx` — 思源黑体接入（next/font Noto Sans SC）+ 元数据更新
- `src/components/landing/hero.tsx` / `navbar.tsx` / `footer.tsx` / `features-section.tsx` — 品牌与宣传文案升级
- `src/app/(auth)/login/page.tsx`、`src/app/(auth)/register/page.tsx`、`src/components/layout/dashboard-layout.tsx` — 品牌字样统一
- `src/app/globals.css`、`tailwind.config.ts` — 思源黑体字体栈
- `README.md` — 使用步骤重写（npm 为主，面向零基础用户）
- `package.json` — 版本号提升至 1.1.1
- `.env`、`.env.local` — NEXT_PUBLIC_APP_NAME 更新为"后现代咖啡馆"
- `.gitignore` — 忽略 `.env`（含密钥，原被跟踪存在泄漏风险）

- mission.md 已从 git 跟踪中移除，不再随仓库推送
