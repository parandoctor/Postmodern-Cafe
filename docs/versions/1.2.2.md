# v1.2.2

## 更新内容

侧边栏结构统一：去掉"私有空间"外框，使其与"工作区"同级并列；今日任务、随时记写、音乐盒三个私有空间项目同列对齐，标题点击均可进入中间操作台的全屏工作台页面（新增今日任务页、音乐盒页）；任务管理固定"长期任务"分组（无截止日期任务），与今日任务明确区分。

## 主要新增文件

- `src/app/dashboard/today/page.tsx` — 今日任务工作台页面（全屏呈现 + 添加 / 完成 / 删除）
- `src/app/dashboard/music/page.tsx` — 音乐盒工作台页面（全屏播放列表 + 上传 / 播放 / 删除）
- `docs/开发日志[2026.8.15-1.2.2].md` — 本版本开发日志

## 主要修改

- `src/components/layout/dashboard-layout.tsx` — 私有空间去框，与工作区同级并列；分组标题样式统一
- `src/components/layout/sidebar-todo.tsx` — "今日任务"标题改为页面入口（跳转 /dashboard/today），仅显示今日到期任务（无截止日期任务归入长期任务）
- `src/components/layout/sidebar-music.tsx` — "音乐盒"标题改为页面入口（跳转 /dashboard/music），快速播放区保留可折叠
- `src/app/dashboard/tasks/page.tsx` — 时间线视图"未设置日期"分组更名为"长期任务"并固定呈现（空态占位提示）
- `package.json` — 版本号提升至 1.2.2
- `README.md` — 同步更新至 v1.2.2（功能说明 / 目录树）

## 其他

- 今日任务与音乐盒工作台页面复用既有 Server Actions 与 zustand store，无新增数据库表
- 任务管理时间线视图的"长期任务"分组固定置底，即使为空也保留占位提示，与今日任务形成明确区分
