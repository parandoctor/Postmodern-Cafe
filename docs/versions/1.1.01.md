# v1.1.01

## 更新内容

首页改为黑白单色天体蓝图科技风格：Hero 区域用 SVG 轨道曲线 + 十字定位标识 + 月球纹理替代 Three.js 粒子系统；导航栏居中 Notion 风格；功能卡片精简为六项并去除"七彩分类"文案，底部链接同步清理。分类管理界面改为天体轨道曲线背景 + 坐标十字定位点 + 月球灰度肌理 + 蓝图草稿质感 + 透明渐变分类卡片。侧边栏支持左右拖动调整宽度（200–480px），右侧面板可切换。随时记写新增展开到工作台的全屏模式（75vh 模态框）。侧边栏待办/记写/音乐添加图标并统一 Notion 圆角与悬停交互。左侧边栏去除概览板块。全部 localStorage 持久化按账号隔离，壁纸旧版 preset 数据自动清理。首页无底部七色滚动带与左下角悬浮元素。
