# v1.3.0

## 更新内容

文件管理四个板块补齐：左栏二级目录（我的文件 / 分类管理 / 收藏夹 / 最近使用 / 回收站）改为真实路由，点击即可切换，选中态由路由推导，深链接与浏览器前进后退均正常；入口默认进入「我的文件」，旧链接 /dashboard/files?tab=xxx 保持兼容。背景壁纸自定义修复：上传后立即可见，工作台面板转为半透明并加遮罩，文字依旧清晰；同时收紧 data URL 体积红线、持久化写入失败不再中断上传，刷新后仍保留壁纸。音乐盒本地音乐上传修复：上传改走新的 /api/music/upload 接口，绕开 Server Action 请求体上限，解决大体积音频上传报 "Unexpected end of form" 的问题；上传失败原因在侧栏与音乐盒页面直接展示。Server Actions 请求体上限同步由 50mb 提到 110mb。

## 其他

- 根因说明：文件板块失效源于 App Router 软导航不触发 popstate；壁纸失效源于 localStorage 配额溢出导致持久化抛错被静默吞掉；音乐上传失败源于 Server Action 请求体上限截断 multipart
- 本地验证：`npx tsc --noEmit`、`npm run build` 通过；/dashboard/files、/categories、/favorites、/recent、/recycle、/music 登录态 HTTP 200、未登录 307；/api/music/upload 小文件、60MB 文件上传成功，非法类型与未登录返回明确错误
- 测试产生的音乐记录与文件、临时会话已清理，未触碰既有用户数据
