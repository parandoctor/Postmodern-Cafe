# v1.2.5

## 更新内容

为 主页、登录注册页、后台系统 添加电机背景音乐：进入页面自动尝试播放，被浏览器拦截时首次交互后自动续播；右下角提供播放 / 暂停与静音控制；页面跳转不中断；与音乐盒本地曲库互斥播放。AGENTS.md 加入 .gitignore 并移出版本库，不再随仓库上传云端。本地 main 与远端同步（基于 v1.2.4 基线开发）。

## 主要新增文件

- `public/audio/bgm-default.m4a` — 默认背景音乐音频资源
- `src/components/ui/default-bgm.tsx` — 默认背景音乐播放器组件
- `src/store/bgm.ts` — 背景音乐全局播放状态

## 主要修改

- `src/app/layout.tsx` — 根布局挂载默认背景音乐，主页 / 登录注册页 / 后台系统统一生效
- `src/components/layout/sidebar-music.tsx` — 音乐盒开始播放时自动暂停默认背景音乐
- `.gitignore` — 新增 agents.md / AGENTS.md，防止上传云端
- `package.json` — 版本号 1.2.4 -> 1.2.5
- `README.md` — 版本号、项目简介、核心功能表与项目目录树同步至 v1.2.5
- `docs/开发日志.md` — 版本记录表新增一行
- `docs/版本更新流程.md` — 恢复并同步至仓库（此前为本地独有）

## 其他
