# v1.2.9

## 更新内容

后台系统改为 D5 三栏结构：左栏导航（工作区 / 私有空间）、中栏工作台、右栏日历与计时读数面板；文件管理五个子视图迁移到左栏二级目录（分类管理 / 我的文件 / 收藏夹 / 最近使用 / 回收站）。分类管理重新设计：取消颜色分配，改为自定义分类名 + 重要性四档（核心 / 重要 / 常规 / 归档），同档内可拖拽排序，分类详情路由改为按 id 访问。背景音乐与音乐盒完全独立：各自状态与音频实例，不再互相暂停，可同时播放；音乐盒默认保持空库，不内置任何曲目。深色主题覆盖文件管理、任务管理、随手记等关键页面。构建移除 Google Fonts 依赖，改用系统字体栈以支持离线构建。
