# 开发日志 [2026.8.15]

## Plan / 策划

用户提出的三项功能更新需求：

1. 随时记写入口点击后应页面化，在中间操作台全文呈现，而不是附在侧边栏左边。
2. 文本过长影响观览，删除左上角的随时记写入口，统一放在左边侧边栏。
3. 每日待办与任务管理功能重叠，每日待办合并在任务管理里，构筑长期工作流；每日完成的任务由空圆圈变为实心圆圈。

结论：需求 1 与 2 互补——侧边栏保留随时记写入口，点击跳转独立工作台页面，长文本换行展示；需求 3 将每日待办整体移除，侧边栏"今日任务"直接调用任务管理 API，完成状态用实心圆圈表达。

- `src/components/tasks/task-card.tsx`、`src/app/dashboard/tasks/page.tsx`：任务完成图标统一为实心圆圈（`<Circle className="fill-foreground" />`）。
- `src/components/layout/dashboard-layout.tsx`：移除顶栏随时记写按钮与 NotesModal 引用，工作区缩进修正。
- 每日待办代码整体移除：`src/actions/widgets.ts`（getTodos / addTodo / toggleTodo / removeTodo / clearDoneTodos / importLocalTodos）、`src/store/widgets.ts`（useTodoStore）、`src/lib/validations.ts`（todoTextSchema）、`src/types/index.ts`（TodoItem）、`prisma/schema.prisma`（Todo 模型与 User.todos 关系），并执行 `npx prisma db push` 同步数据库（原 Todo 表无数据，删除无风险）。
