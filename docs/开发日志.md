## Plan / 策划

### v1.1.0：后台系统 UI 全面重做

目标需求：
- 取消七种彩色分类，改为黑白灰阶（不触碰数据库与服务端逻辑，只替换颜色值）
- 统一 Notion 风格：黑白简洁 + 立体感阴影
- 侧边栏按 Notion 风格重做，保留原有图标
- 删除左下角悬浮小球（光标拖尾 CursorTrail）及其功能
- 右侧新增日历、计时器
- 左侧新增每日待办、随手记、音乐盒（支持本地上传音乐播放）
- 背景壁纸：下架所有预设壁纸，仅保留默认浅色与自定义壁纸

方案决策：
- 保留 `RainbowColor` 类型键（red/orange/yellow/green/blue/darkblue/purple）与 `RAINBOW_COLORS` 记录结构，
  仅替换 hex 为黑白灰阶值，避免改动数据库、服务端 actions、zod 校验与 `categories/[color]` 路由。
- 音乐曲库用 IndexedDB 持久化（localStorage 容量不足以存音频 dataUrl）。
- 浅灰阶颜色下图标/文字对比度不足，新增 `getContrastColor()` 自动对比函数。

### v1.1.0 补充（2026-08-02）全息测绘背景

需求背景：
- 删除神经网络球体周围的胶囊形外框（双层圆角长椭圆封闭轮廓线），不要大型包围环线
- 左上角黑色球体改为单色黑白全息线框数字地球：HUD 测绘蓝图、线稿矢量轮廓、大陆海岸线点阵勾勒、环绕轨道细线、坐标刻度标尺、十字定位标记、深空黑背景、纤细发光白线、粒子点阵肌理、无实体填充、全息投影质感
- 登录/注册页背景取消空白：全息线框地球居中、多层环绕轨道、边缘轻量化测绘刻度、低透明度不刺眼、纯黑背景、黑白单色、可叠加文字、不干扰前景 UI

新增文件：
- `src/components/ui/holo-earth.tsx` — 全息线框数字地球组件：经纬网格 + 简化大陆轮廓（欧亚/非洲/北美/南美/澳洲/格陵兰/南极，经纬度坐标插值采样）点阵勾勒（`strokeDasharray: 0.4 3.4` + round 线帽）；JS rAF 驱动 rotateY 正交投影实现 3D 自转，按平均深度逐条调 opacity（正面亮背面暗）；feGaussianBlur 发光滤镜；环绕轨道细线/坐标刻度（0° 180° 90°W 90°E）/十字定位可配置
- `src/components/ui/auth-earth-background.tsx` — 登录/注册页深空测绘背景：纯黑 + 中央全息地球（低透明度 0.42）+ 多层环绕轨道（bp-dash-flow 缓慢流动）+ 24 刻度边缘标识 + 90 个低透明度闪烁粒子 + vignette
- `src/app/(auth)/layout.tsx` — auth 路由组黑底布局（fixed 背景层 + z-10 内容层）

修改文件：
- `src/components/ui/blueprint-overlay.tsx` — 移除三颗 NeuralOrb 行星的胶囊扫描环（bp-spin-slow/bp-spin-rev 圆角椭圆外框）；左上角行星替换为 HoloEarth（112px，白色线框，置于左上黑盘深空背景内）；右上大黑网/右下小灰网保留 NeuralOrb 仅去环
- `src/app/(auth)/login/page.tsx`、`src/app/(auth)/register/page.tsx` — 去掉 bg-background 白底，卡片改 `bg-black/55 backdrop-blur-md` + 白字；输入框 `!border-white/20 !bg-white/5`；提交按钮改白底黑字（原 outline）；图标/链接/错误提示改白色系
- `src/app/(auth)/login/page.tsx`、`src/app/(auth)/register/page.tsx` — 卡片透明度二次调整：`bg-black/55 backdrop-blur-md` → `bg-black/10 backdrop-blur-[2px]`，让中央地球轮廓经卡片透出（已浏览器验证，文字仍清晰可读）
- `src/app/(auth)/login/page.tsx`、`src/app/(auth)/register/page.tsx` — 卡片透明度三次调整：`bg-black/10 backdrop-blur-[2px]` → `bg-black/5`（移除全部模糊），地球完全透出且无模糊，输入框自带 `!bg-white/5` 保证文字可读

技术要点：
- 刻度线浮点坐标 SSR 与客户端 `Math.cos/sin` 尾数不一致会触发 hydration mismatch 警告，需 `Number(n.toFixed(2))` 固定精度
- HoloEarth 动态 polyline 由 useEffect rAF 每帧 setAttribute 更新 points/opacity，不触发 React 重渲染，性能可控（约 43 条线 + 40 粒子）
- 根 layout 的 BlueprintOverlay（z-0）与 auth 背景（fixed z-0 黑底）同层，后者 DOM 靠后自然覆盖前者

## Questions / 瓶颈点

- 音乐文件以 base64 dataUrl 存入 IndexedDB，大文件占用存储较多；后续可考虑 IndexedDB 直接存 Blob 或引入本地文件句柄（File System Access API）
- 浅灰阶（白/浅灰）下分类图标与文字对比度需靠 `getContrastColor()` 动态处理，后续若引入更多自定义颜色需覆盖更复杂场景
- 右侧面板在 <lg 屏幕下默认隐藏，移动端未提供抽屉入口（仅桌面可用）
- 壁纸下架后，旧用户可能仍存有 wallpaper 的 preset 值，未做迁移清理
