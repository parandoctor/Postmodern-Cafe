## Plan / 策划

### 一、参考图风格分析

参考图为一张"界面研究（Interface Study）"风格的概念 UI 拼贴图，整体美学是"科幻极简 + 数据可视化"的融合，关键词可概括为：黑白单色、界面拼贴、蓝图线稿、多窗口叠放、技术标签。

#### 1. 配色

- 纯白画布底（#FFFFFF）作为基底，整体以黑白灰构成绝对主导。
- 近黑（#000000 ~ #111111）用于窗口边框、标题与图形主体。
- 中灰至浅灰（#888888 ~ #E0E0E0）用于辅助线、网格、半透明遮罩与次要文本。
- 不依赖彩色，仅靠明度对比制造焦点（白字压黑底的高反差）。
- 局部存在"墨水晕染/烟雾"状灰阶纹理，为纯几何结构增加有机流动感。

#### 2. 字体

- 无衬线细体（Light / Thin）为主；英文标题大写，字距宽松（letter-spacing 约 2-4px），如 "ORBITAL FRAMEWORK"、"INTERFACE STUDY"。
- 编号与说明文字使用小号等宽/窄体无衬线（PHASE_01、MAPPING UNKNOWN STRUCTURES、ARCHIVE /009），带技术文档感。
- 排版以左对齐为主，部分标题居中；数字编号（001、002）用等宽字体增强科技感。

#### 3. 界面元素

- 多个模拟浏览器窗口（macOS 风格红黄绿控制点、地址栏占位、汉堡菜单图标），圆角约 8-12px，边缘轻阴影，窗口之间旋转、重叠摆放形成空间纵深。
- 窗口内为左右/上下分栏卡片：左侧文本说明 + 列表，右侧抽象图形（线框星球、隧道、星图）。
- 微交互元素：描边关闭按钮、+ 号添加按钮、← → 翻页箭头、○ 单选、细长滚动条指示器、档案标签（ARCHIVE /009）。

#### 4. 视觉层次

- 第一层：最前方完整窗口（最大、最清晰、无遮挡）。
- 第二层：中间层窗口（稍小、部分被遮挡但具完整性）。
- 第三层：后方窗口降低不透明度（约 60-80%），强化景深。
- 背景层：坐标轴、网格、靶心、虚线圆弧等几何装饰，透明度 20-40%，起装饰不抢主体。

#### 5. 装饰与质感

- 柔和投影（约 0 10px 30px rgba(0,0,0,0.1)），方向统一向下偏右。
- 窗口边缘细微亮边（内发光/亮边框），模拟玻璃质感。
- 少量径向渐变用于星球表面（亮灰到暗灰过渡）；烟雾图形为程序化噪波质感而非均匀渐变。
- 轨道线、连接线多用虚线/点划线，暗示运动轨迹与数据流。

### 二、与项目现状的关联

项目已有基础与该风格高度接近，属于"从蓝图背景升级到界面拼贴"的自然演进：

- 已实现黑白灰阶 Notion 后台（v1.1.0）与 `RAINBOW_COLORS` 灰阶化，全局无彩色。
- 已有 `src/components/ui/blueprint-overlay.tsx`（天体轨道、坐标十字、粒子点阵）与 `src/components/ui/holo-earth.tsx`（全息线框数字地球）。
- 登录/注册页已为纯黑测绘背景 + 深色玻璃卡片；字体为思源黑体体系（tailwind 已配置 mono 字体）。

差异点：

- 现有风格偏"背景图案"驱动，参考图偏"多窗口叠放 + 数据面板"驱动，几何装饰更克制，层次感来自窗口拼贴而非仅背景。
- 现有首页大标题为粗体（font-bold），参考图为细体大字 + 宽字距；中文不适合全大写，需用英文小标签承担"宽字距大写"角色。
- 现有卡片为通用圆角卡片，缺少"窗口框架（标题栏 + 地址栏 + 内容区）"的拟物结构。

### 三、前端实现方案

#### 1. 设计令牌层（`src/app/globals.css`、`tailwind.config.ts`）

- 新增灰度阶变量：--ink-950（#0A0A0A）、--ink-900（#111111）、--ink-600（#666666）、--ink-400（#888888）、--ink-200（#E0E0E0）、--ink-100（#F2F2F2）。
- 新增工具类：
  - `.window-panel`：圆角 10px + 双层阴影（1-2px 接触 + 10-30px 扩散）+ 1px 顶部亮边模拟玻璃。
  - `.label-tech`：等宽小号编号标签（PHASE_01 / ARCHIVE /009），灰底描边。
  - `.title-display`：细体 + 大号 + letter-spacing 0.18em，用于英文展示标题。
- 字体：正文保留思源黑体；英文标题与编号复用现有 mono 栈，如需更细字重可引入 Inter/Space Grotesk 细体（可选，不强制新增依赖）。

#### 2. 组件层（新增 `src/components/ui/`）

- `window-frame.tsx`：窗口框架组件。标题栏（单色化三圆点或坐标小方块、标题、关闭按钮）+ 可选地址栏 + content 插槽；支持 rotate 角度与 z 层级 props，用于拼贴叠放。
- `tech-label.tsx`：等宽编号/档案标签（001、PHASE_01、ARCHIVE /009）。
- `blueprint-grid.tsx`：坐标网格 + 靶心 + 虚线圆弧背景层（低透明度，可并入现有 BlueprintOverlay 或独立成层）。
- `orbit-lines.tsx`（可选）：虚线轨道 + dash 流动动画。
- 装饰图形组件：SVG 灰阶星球（径向渐变）、低透明度烟雾墨迹（feTurbulence 噪波），供首页与空状态插画使用。

#### 3. 页面落地（按优先级）

1. 首页 Hero（`src/components/landing/hero.tsx`）：标题上方加英文窄体小标签（如 POSTMODERN CAFE / ORBITAL FRAMEWORK）；背景叠加坐标网格与虚线圆弧；CTA 按钮保持黑白但强化描边；下方三张功能卡片改为窗口框架样式（标题栏 + 内容区）。
2. 登录/注册（`src/app/(auth)/`）：保留黑底，叠加坐标刻度与窗口角标（如 SYSTEM ACCESS / ARCHIVE 009），卡片可局部窗口化。
3. Dashboard 空状态（任务、文件、回收站等）：用窗口拼贴插画替代空白，前端 SVG 绘制，不引入图片资源。
4. 侧边栏与列表：保持 Notion 黑白，列表项加等宽编号（001/002）增强技术感，不动数据与服务端。

#### 4. 动效

- 复用现有 bp-dash-flow、bp-twinkle、bp-float 动画。
- 新增：窗口 hover 轻微旋转归正、编号标签逐个淡入、轨道线 dashoffset 流动。
- 原则：低速、小幅度、非无限循环优先；遵循 prefers-reduced-motion。

#### 5. 边界与克制

- 不引入彩色、不使用真实照片纹理；装饰层透明度不超过 40%，保证文字可读。
- 中文无大写概念，宽字距仅用于英文标签与数字；中文标题保持正常或适度字距。
- 窗口拼贴仅用于概念展示/空状态，不改变实际交互结构（可点区域仍为真实 DOM）。

### 四、实施路线建议

- Phase 1：设计令牌 + 工具类 + window-frame / tech-label 组件，独立可验证。
- Phase 2：首页 Hero 与功能卡片窗口化。
- Phase 3：登录/注册与后台空状态落地。
- Phase 4：动效与细节打磨，按惯例补充 Coding / Target / Questions / Follow 章节。
- 目标版本：建议落在 v1.2.1（延续 mission.md 中的 1.2 -> 1.2.1 方向），具体以实施轮次确认为准。
- 本轮仅策划，未产生代码改动。

## 附：参考图风格生成提示词

> 以下提示词可用于 AI 图像生成（产出该风格的视觉稿/样机），也可作为给 AI 前端开发者的设计简报，直接描述目标 UI 风格。

为"后现代咖啡馆"（文件管理与生活事务综合服务平台）设计一张"界面研究（Interface Study）"风格的概念 UI 拼贴视觉稿。

整体风格：科幻极简 + 数据可视化 + 界面拼贴，呈现数字蓝图/测绘草稿质感；黑白灰单色系，无任何彩色。

配色：纯白画布底（#FFFFFF）；近黑（#111111）用于窗口边框、标题与图形主体；中灰（#888888）与浅灰（#E0E0E0）用于辅助线、网格与次要文本；仅靠明度对比制造焦点，可含少量低透明度"墨水晕染/烟雾"灰阶纹理。

字体：无衬线细体；英文标题大写、字距宽松（letter-spacing 约 2-4px），如 "ORBITAL FRAMEWORK"、"INTERFACE STUDY"；编号与说明用小号等宽字体（如 PHASE_01、MAPPING UNKNOWN STRUCTURES、ARCHIVE /009），体现技术文档感。

界面元素：多个 macOS 风格浏览器窗口 mockup（顶部红黄绿控制点、地址栏、菜单图标），窗口圆角 8-12px、柔和投影、以不同角度旋转并层叠摆放形成空间纵深；窗口内为"左侧文本/列表 + 右侧抽象图形（线框星球、轨道、星图）"的分栏卡片；包含描边关闭按钮、+ 号、← → 翻页箭头、○ 单选、细长滚动条等微交互元素。

层次与装饰：最前方窗口完整清晰，中层窗口稍小且部分遮挡，背景窗口透明度 60-80%；背景铺满低透明度（20-40%）的坐标网格、坐标轴、靶心与虚线圆弧；轨道与连接线用虚线/点划线并暗示数据流动；阴影柔和（约 0 10px 30px rgba(0,0,0,0.1)），窗口边缘有细微亮边模拟玻璃质感。

用途与排版：作为产品官网着陆页视觉稿，顶部居中英文小标签（如 POSTMODERN CAFE），页面居中超大标题，主文案"让生活与事务管理更加高效快捷"，副文案"生活记录 · 资料归档 · 事务处理"，下方两个行动按钮（立即开始 / 分类浏览）与三张功能卡片（极速上传 / 安全可靠 / 分类管理），底部滚动提示；栅格对齐、层次分明、留白充足，文字清晰可读，装饰不遮挡交互组件；现代网页 UI 设计，高清网页样机。
