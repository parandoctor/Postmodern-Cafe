# 开发日志 [2026.8.15-1.2.2]

> v1.2.2 开发记录：私有空间去框与工作区同级、今日任务与音乐盒页面化、任务管理固定长期任务分组。
> 规则：不包含 emoji，语言简洁，标注新增功能/文件的落点。

---

## Plan / 策划

用户提出的三项功能更新需求：

1. 工作区与私有空间不在同级：私有空间带外框（border-t 分隔容器），视觉上像嵌套，应去掉外框并与工作区同级并列。
2. 今日任务、随时记写、音乐盒不在同一竖列，视觉别扭：本质是今日任务与音乐盒无法在中间操作台全屏打开（仅随时记写已页面化），需把今日任务与音乐盒也做成可打开的项目。
3. 任务管理固定记录"长期任务"：无截止日期任务归入长期任务，与今日任务区分，避免混在同一组。

结论：私有空间分组按钮样式对齐工作区（去掉 border-t/pt-2 容器）；今日任务与音乐盒标题改为页面入口，新增独立工作台页面；任务时间线视图"未设置日期"更名为"长期任务"并固定置底呈现。

## Coding / 关键

- `src/components/layout/dashboard-layout.tsx`：私有空间区块移除 `border-t border-whisper pt-2` 容器，分组标题按钮与工作区完全同格式，二者同级并列。
- `src/components/layout/sidebar-todo.tsx`：标题重构为页面入口（ListChecks 图标 + "今日任务"文字 + Maximize2 图标），点击跳转 `/dashboard/today`；折叠按钮仅控制快速记录区；isToday 改为仅匹配今日到期任务（无截止日期不再计入今日任务）。
- `src/components/layout/sidebar-music.tsx`：标题重构为页面入口（Disc3 图标 + "音乐盒"文字 + Maximize2 图标），点击跳转 `/dashboard/music`；折叠按钮仅控制快速播放区。
- `src/app/dashboard/today/page.tsx`：新增今日任务工作台页面，全屏卡片网格呈现今日到期任务，支持添加（截止日期=今日）、完成切换、删除、跳转全部任务管理。
- `src/app/dashboard/music/page.tsx`：新增音乐盒工作台页面，全屏播放列表卡片网格，支持上传 / 播放暂停 / 删除 / 本地音乐迁移，当前播放曲目常驻顶部。
- `src/app/dashboard/tasks/page.tsx`：时间线视图 GROUP_LABEL["no-date"] 由"未设置日期"改为"长期任务"；分组构建强制固定呈现长期任务组（空态显示"暂无长期任务"占位提示）。
- `package.json`：版本号 1.2.1 -> 1.2.2；`README.md` 同步更新版本徽章、功能说明与目录树。

## Target / 目标需求

- 工作区与私有空间同级并列，私有空间外框移除。
- 今日任务、随时记写、音乐盒三列对齐，均可点击标题在中间操作台全屏打开。
- 任务管理固定"长期任务"分组，与今日任务区分。
- 版本号 1.2.1 -> 1.2.2，开发日志与版本文档同步更新，README 同步。

## Questions / 瓶颈点

- 今日任务工作台与音乐盒工作台均复用既有 Server Actions 与 zustand store，无新增数据库表，无迁移风险。
- 音乐页复用 useMusicStore 的 currentId 状态，与侧边栏播放器共享同一播放上下文，切换页面不中断播放。

## Follow / 优化拆解

- 今日任务页可进一步支持拖拽排序与优先级筛选，与任务管理能力对齐。
- 音乐盒页可扩展播放列表、循环 / 随机模式、进度拖动。
- 长期任务分组后续可在列表视图同步固定呈现，形成双视图一致体验。
