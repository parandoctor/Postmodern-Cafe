技术要点：
- 输入框失焦根因：Entrance 每次渲染调用 motion.create(as) 生成新组件类型，React 判定元素类型变化而卸载重建子树；useMemo 缓存后修复
- BGM 单例：new Audio() 存模块作用域，不再渲染 audio JSX；play/pause/timeupdate 事件写回 store 与 sessionStorage
- 布局根因：卡片 absolute top-1/2 -translate-y-1/2 垂直居中，视口低于卡片高度时底部溢出，且外层 overflow-hidden 无法滚动；改 flex items-center + max-h + overflow-y-auto

## Target / 目标需求

- 首页右栏剪影档案图落地，左侧内容左对齐
- 登录/注册卡片高透明、背景清晰、按钮柔和动态
- 输入框连续输入不失焦
- BGM 进入首页自动响起、切换页面不中断、刷新续播、播放流畅无卡顿
- 登录/注册小视口（1280x700）下所有表单元素完整可见
- `npx tsc --noEmit` 与 `npm run build` 通过

## Questions / 瓶颈点

- build 与 dev 交替运行会污染 .next 缓存，导致 main-app.js 等 chunk 404、React 未水合、页面交互全部失效（表现为音乐不响、点击无反应）；清除 .next 重建后恢复，后续切换前需清理缓存
- headless 测试中无头 Chrome 音频在 seek 到大进度时可能无法缓冲，恢复播放改为等 loadedmetadata 后再 seek/play
- CDP 鼠标事件在 headless 下需要真实 mousePressed/Released 才触发用户手势，且元素需滚动到视口内

## Follow / 优化拆解

1. 首页右栏剪影图可补充轻微扫描线/噪点叠加，增强档案感
2. BGM 可增加音量记忆与淡入淡出
3. 登录注册卡片在极端小屏（<640px 宽）可进一步压缩内边距
