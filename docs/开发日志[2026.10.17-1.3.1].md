# 开发日志 [2026.10.17 - 1.3.1]

## Plan / 策划

目标需求：
- 后台只保留笔记管理、美学空间、实用工具三个模块，以单画布节点图取代左中右分栏
- 首页改为简洁产品落地页，全站统一白底黑字细线视觉
- 修复音乐盒收起和全屏后断播、叠音问题
- 笔记支持 Markdown 编辑、自动保存和多格式文件存储
- 美学空间提供音乐与进阶图片编辑
- 实用工具提供跨页面倒计时和月历
- 删除 Y2K、终端、扫描线、ASCII、蓝图和开发留痕文案

方案决策：
- 使用单实例 MusicProvider 管理唯一 audio 元素，侧栏和页面只读取同一 Zustand 状态
- 登录后直接进入 /dashboard/notes；旧模块路由保留兼容重定向
- 图片编辑器使用 Fabric.js，编辑结果仅下载到本地
- 倒计时按 endsAt 持久化到 localStorage，顶部显示剩余时间
- 数据库先备份，再使用 prisma db push 删除旧模块表与字段，保留用户、笔记、正常文件和音乐

技术要点：
- 音乐断播根因是侧栏音乐组件卸载时同时卸载了 audio；叠音根因是侧栏与音乐页各自创建 audio
- 自动保存使用 800ms 防抖与串行队列，避免旧请求覆盖新内容
- Fabric 编辑器使用 50 步快照历史，裁剪通过调整画布尺寸和对象坐标实现
- 倒计时持久化 endsAt，跨页面和刷新都能根据真实时间恢复
