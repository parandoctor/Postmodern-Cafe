## Plan / 策划

### v1.1.01：首页天体蓝图 + 交互优化 + 存储账号隔离

目标需求：
- 首页改为黑白单色天体蓝图科技风格（SVG 轨道 + 十字定位 + 月球纹理），替代 Three.js 粒子
- 导航栏居中，去除"七彩分类"链接
- 分类管理页背景改为天体轨道曲线 + 坐标十字定位点 + 月球灰度肌理 + 蓝图草稿质感
- 侧边栏可拖动调整宽度（200–480px）
- 随时记写可展开到工作台全屏模式
- 左侧边栏去除"概览"入口
- 所有 localStorage 持久化按账号隔离（待办/笔记/壁纸/UI状态）
- 壁纸旧版 preset 值自动清理
- 首页无底部七色滚动带与左下角悬浮元素

方案决策：
- Hero 不再依赖 Three.js 生态，用纯 SVG 实现天体蓝图背景（无额外依赖）
- 账号隔离使用 `localStorage` 中 `rainbow-box-active-user-id` 键 + Zustand persist 自定义 storage wrapper
- 壁纸只接受 `null` 或 `data:` URL，persist 版本迁移自动清理旧值

## Questions / 瓶颈点

### 构建残留 JSX 问题（2026.8.2 修复）
- `hero.tsx` 和 `categories/page.tsx` 在 `replace_string_in_file` 替换时产生了组件 `}` 之后的孤儿 JSX 代码，导致 webpack 报 `Expression expected` / `Unterminated regexp literal` 错误，整个项目构建失败，所有页面背景空白。
- 解决方案：扫描全部 8 个被修改文件，确认仅两个文件有残留，删除 `}` 之后的多余 JSX，重新构建成功。
