# 开发日志 [2026.10.17 - 1.3.2]

## Plan / 策划

目标需求：
- 恢复并强化中央动态阴影，避免动画存在但几乎不可见
- 三根竖线进一步收紧，模块节点保持错位
- 悬停选项、节点或线条时整组上浮，阴影向对应模块聚拢
- 首页和后台按钮从平面样式升级为有明显反馈的动效按钮
- 首页文字在加载和滚动时逐行渐进出现
- 版本更新为 1.3.2，新建指向 main 的 PR，保留 1.3.1 PR

方案决策：
- 使用 Canvas 2D 重新实现高可见度半调波：持续漂移、呼吸、鼠标位置偏移和悬停聚焦
- 三线位置改为 30% / 50% / 70%，画布控制在约 780×520
- 每根线增加透明点击热区，悬停时线条、节点、标签共享 activeModule 状态
- 新增 MotionButton，统一 primary / secondary / ghost / icon / danger 变体
- 新增 Reveal 与 RevealLines，基于 framer-motion 的 whileInView 实现逐行揭示

技术要点：
- 原动画周期约 28 秒，本次缩短至约 6 秒，并加入鼠标焦点偏移
- 减少动态模式下只绘制静态阴影，Focus 变化时才重绘，不运行持续 RAF
- MotionButton 使用 Framer Motion 的 whileHover / whileTap / animate 组合，主按钮持续浮动
- RevealLines 使用逐行遮罩与上浮，once: true 避免重复播放

## Target / 目标需求

- 中央点阵阴影在正常浏览中明显可见地移动
- 鼠标经过画布时波峰向指针偏移
- 悬停任一模块的节点、标签或线条时，该组上浮且点阵聚焦
- 首页首屏逐行出现，滚动到功能区和 About 时继续逐行出现
- 主要按钮具备上浮、扫光、描边和按压反馈
- 390 / 768 / 1440px 无横向溢出
- npx tsc --noEmit 与 npm run build 通过

## Questions / 瓶颈点

- 三根线收紧后需要避免标签与引线重叠，采用更小标签宽度和位置微调
- 动效增强同时必须控制 Canvas 更新频率，当前约 30fps 并限制 DPR 为 2
- 1.3.2 PR 指向 main 会同时包含 1.3.1 改动，因此两个 PR 均保留 OPEN
